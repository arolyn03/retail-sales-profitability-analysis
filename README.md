Retail Sales \& Profitability Analysis



Project Overview

This project analyzes retail sales data to understand sales performance, profitability, category contribution, and regional trends. It demonstrates an end-to-end data analytics workflow using Python, SQL, SQLite, and Power BI.



Note: The dataset contains synthetic sample data created for portfolio and learning purposes. It does not represent actual business transactions.



Tools \& Technologies

\- Python – Dataset creation and data cleaning

\- Pandas – Data manipulation and validation

\- SQL – Data analysis and business queries

\- SQLite – Database storage and querying

\- DB Browser for SQLite – SQL execution and validation

\- Power BI – Interactive dashboard and visualization



Project Workflow

1\. Created a sample retail sales dataset.

2\. Cleaned and validated the data using Python.

3\. Stored the cleaned dataset in SQLite.

4\. Performed SQL analysis to examine:

&#x20;  - Overall sales and profit

&#x20;  - Category-wise performance

&#x20;  - Monthly sales trends and growth

&#x20;  - Region-wise sales and profitability

5\. Built a Power BI dashboard to visualize key metrics and trends.



Key Metrics

\- Total Orders: 10

\- Total Sales: 12,050

\- Total Profit: 4,290



SQL Analysis

Four SQL scripts are included:

1\. Data validation and baseline metrics

2\. Category-wise sales and profitability

3\. Monthly sales trend and growth using window functions

4\. Region-wise sales and profit margin



Dashboard

The Power BI dashboard presents:

\- Total Sales

\- Category-wise sales
